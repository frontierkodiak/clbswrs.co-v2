# Caleb Personal Tools

A private integration that lets Caleb Sowers use his own Gmail and Google
Drive from the gogcli command-line tool and assistants he authorizes.
It is for the account owner's personal use. It has no public sign-up or
service offered to other users.

The integration uses Google's OAuth consent flow. The account owner chooses
whether to grant access and can revoke it in Google Account settings.
The authorized Gmail permissions can read, compose, send, organize mail,
and manage mail settings. The authorized Drive permission can read, create,
edit, and delete files. An assistant must also have the owner's instruction
for the task it performs.
